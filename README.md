# XTreNDAW

استوديو محتوى ذاتي التشغيل — ينتج حلقات فيديو قصيرة (9:16) بالعربي وينشرها على المنصات، **مجاني بالكامل**، مبني من الصفر على نضافة.

> الأصل الوحيد للمشروع هو هذا المستودع. أي جهاز: `git clone` → `pip install -r requirements.txt` → `python -m xtrendaw.run_cycle`

---

## الحالة

| | |
|---|---|
| الفرع الرئيسي | `main` |
| آخر تحديث | يُحدَّث تلقائيًا مع كل خطوة شغل |
| المحرك | Python 3.12+ (بلا أي خدمة مدفوعة) |
| الجدولة | GitHub Actions (مجاني على المستودعات العامة) |

## قواعد المستودع — إلزامية

1. **مفيش سر في الكود.** المفاتيح في GitHub Secrets فقط (`Settings → Secrets and variables → Actions`).
2. **مفيش ميديا في git.** الفيديو/الصوت/الصور يروحوا Artifacts أو Releases — `.gitignore` بيمنع `*.mp4` و`*.wav` و`*.mp3`.
3. **كل وحدة ليها اختبار ينفذ الكود الحقيقي** — مش فحص صياغة.
4. **أي سقف (يومي/ساعي) مكتوب ومصدره مكتوب جنبه** — مفيش رقم من الهوى.

## مواصفات الفيديو (ثابتة — مفروضة من حدود المنصات)

| البند | القيمة | السبب |
|---|---|---|
| الأبعاد | 1080×1920 (9:16) | مطلوب لـReels/Shorts |
| الإطارات | 30 fps | نطاق 23–60 المقبول |
| الترميز | H.264 + AAC | إنستجرام يرفض غيره (خطأ 24 بلا رسالة) |
| المدة | 35–55 ثانية (حد أقصى **90**) | إنستجرام API: ≤90 ثانية |
| الحجم | ≤40 MB | حد إنستجرام 100 MB — هامش أمان |
| faststart | مفعّل | moov atom في أول الملف — مطلوب |

## البنية

```
xtrendaw/          محرك النظام
  settings.py      إعدادات + أسرار (من البيئة/Secrets فقط)
  content.py       مصنع المواضيع والسيناريوهات
  tts.py           التعليق الصوتي + توقيت كلمة-بكلمة
  scenes.py        المشاهد (stock أو مولّدة برمجيًا)
  captions.py      الكابتشنز المتزامنة
  video.py         التجميع النهائي (ffmpeg)
  publish/         محوّلات النشر لكل منصة
  run_cycle.py     قائد الدورة
state/             الحالة (SQLite) — ضد التكرار
tests/             اختبارات تنفذ الكود الحقيقي
```

## قيود المنصات الحقيقية (مقاسة، مش تقديرية)

| المنصة | الحد | ملاحظة حاسمة |
|---|---|---|
| **YouTube** | ≈6 رفع/يوم (1,600 وحدة من 10,000) | **المشروع غير المُراجَع بيرفع Private غصبًا** مهما حطيت `privacyStatus: public` — لازم Compliance Audit |
| **Instagram** | 100 منشور/24 ساعة · 200 نداء/ساعة | حساب **Business** مربوط بصفحة فيسبوك فقط · ≤90 ثانية · **لازم رابط HTTPS عام للفيديو** |
| **GitHub Actions** | دقائق مجانية بلا حد (عام) | الجدولة **بتتعطل بصمت بعد 60 يوم بلا نشاط** → `keepalive.yml` إلزامي |
| **edge-tts** | مجاني | مقفول في المتصفحات من 2025-12-17، **شغال من السيرفر** · خدمة غير رسمية → طبقة بديلة مطلوبة |
| **Groq (LLM)** | ≈30 طلب/دقيقة | مجاني بلا بطاقة — كفاية لتوليد السيناريوهات |
