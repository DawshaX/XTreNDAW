### ب) عيوب حقيقية لقيتها في كود المحرك (اتقريت سطر بسطر)
1. **`nova/run_cycle.py` — اللغة الإنجليزية مكسورة بالبناء.**
   `groups` و`groups_en` بيتعرفوا جوه `if lang == "ar":` بس، وبعدين بيتستخدموا في `video.assemble(plan, groups if lang == "ar" else groups_en, …)`.
   → لو `NOVA_LANGS=en` (من غير `ar`) هيحصل `NameError`. يعني المسار الإنجليزي مش شغال.
2. **`nova.yml` بيحط `NOVA_DAILY_CAP: "24"` و`NOVA_PLATFORM_GAP_H: "1"`** — مستحيل فعليًا على يوتيوب (شوف §3).
3. **`settings.py` بيحط قيم خاصة كـ defaults جوه كود عام**: `FACEBOOK_PAGE_ID=1265727539958933` و`TELEGRAM_CHAT_ID=1890579200`. مستودع Public → أي حد بيقراها.
4. `git_commit()` بيعمل `git push` من جوه الـrunner — لو الـworkflow بيتحفز بـ`push` هيدخل في سلسلة، ومفيش حماية من تعارض مع job تاني شغال.
5. `pub_youtube.py` بيطلب `"privacyStatus": "public"` — شغال بس لو المشروع عدى الـaudit (شوف §3).

## 3. التصميم المقترح (نظيف من أول يوم)

```
┌──────────────────────────────────────────────────────────┐
│  المحتوى: topic factory (قوالب + Groq مجاني) + بنك حقائق  │
│  → script (hook + 3 حقائق + outro) + title + caption      │
└───────────────┬──────────────────────────────────────────┘
                │
┌───────────────▼──────────────────────────────────────────┐
│  الإنتاج: TTS (edge-tts → بديل محلي) + توقيت كلمة-بكلمة   │
│  → مشاهد (Pexels/Mixkit أو مولّدة برمجيًا) → كابتشنز      │
│  → تجميع ffmpeg → MP4 1080×1920 / 30fps / H.264+AAC      │
│  ★ مواصفات ملزمة: faststart + ≤90s + ≤40MB (لإنستجرام)    │
└───────────────┬──────────────────────────────────────────┘
                │
┌───────────────▼──────────────────────────────────────────┐
│  الحالة: SQLite/JSONL — بصمة ضد التكرار (عنوان+حقائق)     │
│  حالة كل حلقة: queued→scripted→produced→published→failed  │
└───────────────┬──────────────────────────────────────────┘
                │
┌───────────────▼──────────────────────────────────────────┐
│  النشر: adapter لكل منصة (fb / ig / yt) + dry-run         │
│  + فحص الصلاحيات قبل المحاولة + retry + سقف يومي آمن      │
└───────────────┬──────────────────────────────────────────┘
                │
┌───────────────▼──────────────────────────────────────────┐
│  التشغيل: GitHub Actions (مجاني) + keepalive + concurrency│
│  + غرفة تحكم: تلجرام + dashboard على GitHub Pages         │
│  + 3 أخطاء متتالية → إيقاف ذاتي + إنذار                   │
└──────────────────────────────────────────────────────────┘
```

قواعد إلزامية من أول commit:
- **مفيش سر في الكود ولا في المستودع** — Secrets فقط (غلطة الـrepo القديم).
- **مفيش ميديا في git** — Artifacts/Releases.
- **كل خطوة ليها اختبار** ينفذ الكود الحقيقي (مش syntax check).
- **كل رقم سقف بييجي من مصدر مكتوب** مش من الهوى.

## 4. المراحل — وكل مرحلة ليها دليل نجاح ملموس

| مرحلة | الهدف | الدليل اللي هتشوفه بعينك |
|---|---|---|
| **0. العقد** | تثبيت مواصفات الفيديو + الاسم/البراند + المنصات | ملف `SPEC.md` + قرار منك |
| **1. محرك الإنتاج** | من موضوع → **MP4 حقيقي** 1080×1920 بصوت عربي وكابتشنز | ملف `.mp4` تشتغله هنا — **ممكن يتعمل النهارده** |
| **2. مصنع المحتوى** | بنك مواضيع + توليد لا نهائي + حماية من التكرار | 20 حلقة جاهزة + اختبار يثبت مفيش تكرار |
| **3. النشر** | adapters + dry-run + فحص توكنات | تقرير «ناجح/فشل + السبب» لكل منصة |
| **4. الأتمتة** | repo نظيف + Actions ساعية + keepalive | run حقيقي على GitHub بـlog |
| **5. غرفة التحكم** | تلجرام + dashboard + إيقاف ذاتي عند 3 أخطاء | رسالة تلجرام + صفحة حالة حية |
| **6. الجودة** | تحليل أداء المنشور → تحسين العناوين/الأغلفة + بوابة تدقيق الحقائق | تقرير أسبوعي «إيه اللي اشتغل وليه» |

## 5. قرارات محتاجها منك (بعد ما تختار، أبدأ فورًا)
1. **المحتوى**: نفس خط «حقائق قصيرة بالعربي» ولا اتجاه تاني؟
2. **المنصات بالترتيب**: أقترح **فيسبوك + إنستجرام الأول** (أسهل قانونيًا) و**يوتيوب بعد ما نتأكد من حالة الـaudit**.
3. **نبدأ بأنهي مرحلة؟**
4. **البراند**: نبني هوية جديدة ولا نستخدم أصول «دوشة» الموجودة في الـrepo القديم؟
